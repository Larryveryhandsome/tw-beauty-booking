傳統做法的痛點 vs. 用系統的優化方案

每一列都可以按右邊的按鈕，直接到示範裡看同一件事怎麼處理。示範為虛構店家「示範美學館」，全部是假資料。

01 預約

✕ 傳統做法

客人 LINE 問「明天下午有空嗎」，老闆一邊做一邊回，來回好幾輪才定下來，還可能排到重疊的時段。

 

✓ 用系統

客人自己選項目、設計師、時段。系統依「設計師 × 時間 × 服務時長」排，染髮 150 分鐘就占 150 分鐘，只顯示真的空的時段。

試預約 →
02 爽約與遲到

✕ 傳統做法

客人忘記或臨時不來，空出一整段時間才發現；要提醒得自己一個個傳。

 

✓ 用系統

前一天、當天自動提醒，客人一鍵「確認出席」或「改期」。原則上能提早知道哪些時段會空出來。

看提醒 →
03 請假改約

✕ 傳統做法

設計師臨時請假，老闆要翻本子，一個個打電話、傳訊息問客人改哪天。

 

✓ 用系統

設計師按請假，系統列出受影響的客人，自動通知並附上可選的新時段，客人自己點選就改好。

一鍵示範 →
04 回訪

✕ 傳統做法

客人做完就沒回來，過了很久才想到「她是不是該補染了」，但沒時間一個個找。

 

✓ 用系統

依項目週期自動提醒回訪：補染約 6 週、補睫約 3 週、凝膠甲約 3～4 週。每個項目的週期都能自己設定。

看回訪名單 →
05 儲值與套票

✕ 傳統做法

儲值、套票靠紙本或 Excel 記，客人問「我還剩幾次」要翻半天，還可能算錯。

 

✓ 用系統

結帳時依套票、儲值金自動扣次、扣額，客人自己在 LINE 查餘額，雙方對得上。

看儲值扣款 →
06 月結

✕ 傳統做法

月底手動加總每位設計師的業績，再逐筆算抽成；指定單、不同項目比例不同，容易算到眼花。

 

✓ 用系統

依服務項目與「客人是否指定設計師」自動算業績與抽成，比例在設定檔裡改，月底一頁看完。

看月結 →
07 空檔（選配）

✕ 傳統做法

平日下午空了一兩個小時，只能在 IG 隨手貼「今天有空檔」，不見得有人看到。

 

✓ 用系統（選配）

找出連續空檔，挑出週期快到的適合熟客，推一則限時空檔優惠，先搶先贏；發送前由老闆確認名單。

3 分鐘看完的順序

  1. 先當一次客人（約 40 秒）選補睫或剪髮，選設計師，挑時段，看預約成功卡片。
    去預約 →
  2. 按「▶ 一鍵示範：設計師請假」（約 40 秒）看請假、找出 3 位受影響客人、自動通知、客人選新時段、總表更新。
    開始 →
  3. 看回訪提醒（約 30 秒）週期到了的客人一目了然，一鍵送提醒；週期可以自己改。
    去看 →
  4. 看儲值扣款與月結（約 60 秒）在預約總表點一筆預約按「結帳」，看餘額自動扣；再到月結看抽成。
    去看 →
